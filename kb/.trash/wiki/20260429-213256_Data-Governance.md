# Data Governance

Key governance decisions identified and discussed through the project's early working sessions.

## Identity Resolution

**Tokenized PAN** is the preferred AEP profile linking key. Raw PAN is not used for security reasons.

**Open question:** Stability across card re-issuance — Dana Mueller (Data Governance) checking with Infosec. If token changes on re-issuance, profile history could break. Not a blocker yet but needs validation before architecture is finalized.

## Retention

**13-month retention for marketing purposes is fine under existing policy.** No legal escalation needed as long as the data is treated as marketing data retention (not a DSR compliance mechanism).

**24 months vs. 13 months:** Open question. Not yet resolved. What is gained/lost at the longer window?

## Dispute and Fraud Data

**Separate governance surface.** If Flywheel ever wants to use dispute status data, need to come back to Governance for a specific review. Not an MVP blocker.

**Implication:** UC3 (dispute suppression) requires a separate ingestion path from the main card authorization feed.

## Declined Transactions

**Stay away from declined transactions in the AEP footprint at MVP.** Decline-reason data has a murky regulatory story. Dana Mueller's recommendation: Phase 2 conversation at earliest.

## Merchant Normalization

MCC codes are garbage for marketing purposes — "5411 Grocery Stores" includes Walmart, Whole Foods, and a bodega in the same bucket.

**Merchant Taxonomy project** (underway by Linh's team) is a 2027 deliverable, maybe late 2026 if everything goes right. If Flywheel blocks on it, Flywheel ships in 2027.

**Middle path:** Curated top-N lookup (top ~500 chains) covering 60-65% of transaction volume. Fast workstream, can be scoped in parallel. Jessica and Linh taking this on.

## Ownership

Data Eng can own the pipeline and the schema. **Data Eng will not own the audience definitions** — those live with consumer teams (Card, Analytics, MarTech). The boundary needs to be explicit; last time it was fuzzy there was a 4-month fight over dormant flag logic ownership.
