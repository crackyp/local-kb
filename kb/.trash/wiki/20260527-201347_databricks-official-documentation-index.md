# Databricks Official Documentation Index

## Summary
This page outlines the structure and key resources of the official Databricks documentation for AWS. It serves as a navigation guide for users seeking technical how-to guidance, reference information, and platform features. The documentation is organized by cloud provider and covers onboarding, data engineering, AI/ML, BI, warehousing, administration, and security. It also highlights new platform capabilities like Lakebase for OLTP databases and Genie, an AI-powered documentation assistant.

## Documentation Structure & Navigation
*   **Cloud Provider Switcher:** Technical documentation is segmented by cloud. Users must select Amazon Web Services, Google Cloud Platform, or Microsoft Azure via the switcher in the upper right corner.
*   **ADi Services:** Separate documentation exists for ADi Services.
*   **Genie AI Assistant:** An integrated AI chatbot ("Genie") is available on the documentation site to answer questions and help users quickly discover relevant information.

## Key Documentation Categories
### Try Databricks
*   Free trial sign-up and guided tutorials.
*   Workspace UI fundamentals for navigation.
*   Data guides for connecting to sources and exploratory analysis.

### Explore Databricks
*   **Data Sharing:** Securely share data and AI assets externally or across metastores.
*   **Data Engineering:** Build ETL pipelines, process large datasets, and orchestrate workflows.
*   **AI and Machine Learning:** Develop, train, and deploy ML models and GenAI apps using MLflow.
*   **Databricks AI/BI:** Create dashboards, reports, and visualizations for business insights.
*   **Data Warehousing:** SQL querying, schema management, and performance optimization.
*   **OLTP Databases (Lakebase):** Fully-managed, PostgreSQL-compatible databases integrated with the Lakehouse.
*   **Develop on Databricks:** Build applications, integrate APIs, and extend functionality with custom code.

### Manage Databricks
*   **Administration:** Account settings, workspace management, user policies.
*   **Security and Compliance:** Access controls, security policies, industry standard compliance.
*   **Data Governance:** Governance frameworks, lineage management, and data quality controls.

### Quick Links & Support
*   **Status Page:** Monitor system status, availability, and maintenance.
*   **Release Notes:** Track product updates, new features, and improvements.
*   **Glossary:** Definitions for technical terms and platform concepts.
*   **Reference:** REST API, SDKs, Python APIs, and Databricks SQL references.
*   **Other Resources:** Limits/quotas, regions, support channels, feedback, training, and migration guides.
