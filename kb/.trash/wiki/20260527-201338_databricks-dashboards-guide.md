# Databricks Dashboards Guide

## Summary
This guide outlines the capabilities and workflows for creating, managing, and sharing data visualizations using Databricks Dashboards on AWS. It covers AI-assisted authoring, dataset configuration, interactive filtering, and collaboration features. The guide also details methods for automating dashboard workflows, integrating with external systems, monitoring usage, and optimizing performance for enterprise reporting.

## Authoring Dashboards
Dashboards transform data into sharable insights, with AI/BI dashboards offering AI-assisted authoring and an enhanced visualization library.
*   **Creation & Organization:** Users can create, view, organize, and delete dashboards. Drafts support collaboration, and keyboard shortcuts streamline editing.
*   **Datasets:** Power visualizations by defining datasets from tables, views, or custom queries.
*   **Visualizations:** Build charts using AI-assisted authoring or manual configuration, with extensive formatting options.
*   **Filters:** Apply global, page-level, and widget-level filters to focus on specific data. Utilize cross-filtering and drill-through for interactive exploration.
*   **Custom Calculations:** Analyze data without modifying the underlying dataset by creating calculated fields and level-of-detail expressions.
*   **Settings:** Customize themes, colors, fonts, and locale settings to match organizational standards.

## Sharing & Collaboration
Published dashboards can be shared with anyone registered to the Databricks account, even if they lack workspace access.
*   **Publish & Share:** Distribute dashboards with shared or individual data permissions at both workspace and account levels.
*   **Schedule & Subscribe:** Set up automated refresh schedules and configure email or Slack subscriptions for published reports.
*   **Embedding:** Integrate published dashboards into external websites and applications using iframes.
*   **Genie Spaces:** Enable natural language data exploration by publishing Genie Spaces alongside dashboards.

## Automation & Integration
Dashboards can be managed programmatically and integrated into broader data workflows.
*   **Import & Export:** Transfer dashboards across workspaces by exporting/importing dashboard files, which can be edited directly for advanced customization.
*   **Source Control:** Use Git integration to version control dashboards and facilitate team collaboration.
*   **Declarative Automation Bundles:** Manage dashboards programmatically using infrastructure-as-code workflows.
*   **REST APIs:** Automate dashboard creation, management, and sharing via Databricks REST APIs.
*   **Lakeflow Jobs:** Schedule dashboard updates using Lakeflow Jobs for automated workflow orchestration.

## Monitoring Usage
*   **Audit & Tracking:** Track dashboard creation, views, and user interactions using audit logs and system tables to monitor engagement and compliance.

## Next Steps & Optimization
*   **Tutorials & Examples:** Follow step-by-step guides to create your first dashboard, use AI-assisted visualizations, or clone pre-built examples.
*   **Performance Optimization:** Implement caching strategies and optimization techniques for large datasets.
*   **Limits & Quotas:** Review numerical limits for dashboards, including page limits and resource quotas.
*   **Data Connection:** Define datasets and connect to tables, views, and custom queries to ensure accurate data representation.
