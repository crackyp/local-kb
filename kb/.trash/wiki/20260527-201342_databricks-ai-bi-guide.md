# Databricks AI/BI Guide

## Summary
Databricks AI/BI is a business intelligence solution on AWS that leverages compound AI to enhance data analysis through self-service insights, governance, and performance. This guide outlines the core tools for building AI-powered dashboards and conversational Genie Spaces, defining Unity Catalog business semantics, and administering AI/BI resources across the organization.

## Core Concepts and Tools
Databricks AI/BI integrates compound AI systems with the broader platform to streamline business intelligence workflows.
*   **AI/BI Concepts:** Focuses on platform integration and how compound AI systems operate to deliver automated insights.
*   **BI Tools:** Provides an overview of available business intelligence tools and third-party integrations within the AI/BI ecosystem.
*   **Genie Interface:** A simplified, user-friendly interface designed for business users to consume AI/BI dashboards, explore Genie Spaces, and interact with Databricks Apps.

## Building and Creating AI/BI Assets
Users can create interactive analytics assets and define consistent data contexts using the following features:
*   **Dashboards:** Create AI-powered, low-code dashboards featuring dynamic visualizations and cross-filtering capabilities for deeper data exploration.
*   **Genie Spaces:** Build conversational interfaces that learn from underlying data, enabling users to ask questions and receive adaptable, AI-generated visualizations.
*   **Unity Catalog Business Semantics:** Define consistent, reusable metrics and semantic context within Unity Catalog. These semantics serve as the foundational data sources for Genie Spaces and dashboards, ensuring alignment across the organization.

## Managing and Administering AI/BI
Administrators and data stewards can govern AI/BI resources, control access, and monitor organizational usage.
*   **Admin Guide:** Covers managing dashboard embedding, utilizing APIs for automation, and auditing AI/BI usage patterns across the enterprise.
*   **Consumer Access:** Details how to configure user access levels and manage consumer permissions for AI/BI resources to ensure secure and appropriate data consumption.
