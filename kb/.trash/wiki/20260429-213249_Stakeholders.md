## Stakeholder Positions

**Priya Raman (Credit Card):**
- Horizon relaunch is the most visible gap; travel-spender audience by Q3 pays for itself
- Cautious on scope — last two AEP expansions overran budget and timeline
- Card does not want to own a data pipeline; wants to consume governed data and build journeys
- 80%+ of use cases answered by aggregated features; don't pay for raw if not needed

**Marcus Webb (Data Engineering):**
- Current Snowflake → AEP nightly push is not broken; constraint is ticket queue is understaffed
- "Bring transaction data into AEP" can mean very different things — don't conflate in vision deck
- 11M transactions/day is not small; AEP pricing at that volume is meaningful
- Data Eng can own the pipeline and the schema, will not own audience definitions

**Jessica Chen (Marketing Analytics):**
- Analytics has been asking for event-level data in AEP for over a year
- Feature-layer pattern fits stable use cases; Meridian's use cases aren't stable anymore
- Argues for Option B (raw events) but acknowledges cost concern

**Rachel Okonkwo (Campaign Ops):**
- Self-service audience authoring has a shadow cost on Campaign Ops (governance, QA, kill-switch patterns)
- Suppression signals need to be global — applicable to all marketing channels
- Must be in the loop on governance decisions

**David Kowalski (VP MarTech):**
- Wants this to be the MarTech play of the year, not a feature request dressed up as a project
- Wants credible cost envelope before steerco, not bottoms-up estimate
- Guidance: pitch as three specific marketing wins, not a platform project
